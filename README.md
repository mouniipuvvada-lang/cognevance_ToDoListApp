# To-Do List Mobile App

Level 1 Android App Development project for the Cognevance internship task.

## Features

- Add tasks
- Update tasks
- Delete tasks
- RecyclerView task list
- Local SQLite database
- Input validation
- Delete confirmation
- User-friendly dialogs

## Technologies

- Kotlin
- XML
- Android SDK
- RecyclerView
- SQLite
- Material Design

## How to Run

1. Install Android Studio and Android SDK.
2. Open this project folder.
3. Let Gradle sync and download dependencies.
4. Connect an Android phone with USB debugging enabled or start an Android emulator.
5. Run the `app` configuration.

VS Code can be used for editing, but Android SDK/Gradle/JDK must be installed for building and running the Android application.

## Project Requirements Covered

- UI design
- Add, update and delete
- RecyclerView
- SQLite local storage
- Validation
- Testing
- APK generation
